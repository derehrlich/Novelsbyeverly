    Musik

    –

    So kommt YouTube Music ins Overlay

    Variante 1 (lokal, am einfachsten): Die YouTube-Music-Desktop-App (Pear Desktop, früher „th-ch/youtube-music“) hat ein Plugin „Tuna OBS“. Zusammen mit dem OBS-Plugin Tuna (als Quelle „Web browser“ wählen und „Host/receive information on local webserver“ mit Port 1608 aktivieren) steht der aktuelle Titel unter http://localhost:1608/. Hier „Anzeige: lokal“ wählen und diese Adresse eintragen. Das Overlay liest sie selbst, es muss auf demselben PC laufen wie OBS.

    Variante 2 (Server): „Anzeige: Server“ wählen. Dann kommt der Titel per Chat (!song Titel - Interpret, !song aus), von Hand (oben) oder von einem Hilfsprogramm, das POST /api/musik mit dem INGEST_TOKEN aufruft.

    Hinweis: Lizenzierte Musik im Stream kann auf Twitch zu stummgeschalteten Videos führen.

    Twitch & Chat

    1 · Twitch-App

    Lege auf dev.twitch.tv/console/apps eine Anwendung an (Client Type: Public, OAuth Redirect URL: http://localhost) und trage ihre Daten hier ein.

    Die Daten liegen im Datenordner des Servers. Das Secret wird nie wieder angezeigt. Wechselst du die Client-ID, musst du Kanal und Bot neu verbinden.

    2 · Verbindungen

      Für den Bot-Account vorher bei Twitch ausloggen oder ein privates Fenster nutzen und dort mit dem Bot-Konto anmelden. Der Bot sollte in deinem Chat Moderator sein.

      System

      Sicherung

      Lädt alle Einstellungen, Ziele, Aufgaben, Zugänge und Zähler als ZIP herunter.

      ⬇ ZIP herunterladen

      Mit Zugängen enthält die Datei Passwörter-ähnliche Daten (Tokens, Secret). Bewahre sie privat auf.

      Wiederherstellen

      Spielt eine Sicherungs-ZIP ein und ersetzt die aktuellen Daten. Vorher legt der Server automatisch eine Sicherung des jetzigen Stands an.

      Update

      Läuft: –

      Lade eine ZIP der neuen Version hoch (der Ordner mit server, public und package.json, z. B. „Download ZIP“ von GitHub). Der Server prüft sie, sichert vorher deine Daten und startet neu. Deine Daten bleiben erhalten.

      Läuft der Server nicht im Docker (restart: unless-stopped), musst du ihn nach dem Update selbst neu starten.
